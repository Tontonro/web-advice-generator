# Web Advice Generator

Gerador de conselhos aleatórios para estudo de consumo de APIs.

---

## Sobre

Projeto simples que consome a [Advice Slip API](https://api.adviceslip.com/) e exibe conselhos aleatórios com um clique. Desenvolvido para praticar integração com APIs REST usando JavaScript puro.

---

## Tecnologias

- HTML5
- CSS3
- JavaScript (fetch/async-await)
- Advice Slip API
